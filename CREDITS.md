# Crédits

## Modèles 3D
Tous les modèles 3D viennent de **Quaternius** (https://quaternius.com), sous licence
**CC0 1.0** (domaine public : usage commercial autorisé, attribution non obligatoire
mais faite ici par reconnaissance). Ils ont été récupérés sur Poly Pizza.
La liste exacte (page source, fichier, licence) est dans `scripts/models.json`.

Les personnages ont été « habillés » pour l'époque biblique dans le code
(`src/game/characters.ts`) : tunique, ceinture, voile, couleurs.

## Créé pour Zion
- Maisons, tour, remparts, fontaine, scène, arche : construits en code (`src/game/buildings.ts`).
- Textures (enduit, pierre, pavés, bois, herbe) : dessinées en code (`src/game/textures.ts`).
- Musique générative et bruitages : synthétisés en code (`src/core/music.ts`, `src/core/audio.ts`).
